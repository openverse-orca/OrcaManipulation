# 快速开始

流程：**装环境 → 起仿真 → 采集 → 回放 →（服务器）训练推理**

脚本目录：`src/examples/d12_competition_warehouse/`，conda 环境 `orcalab_lerobot`。

## 0. 装环境（首次）

```bash
conda create -n orcalab_lerobot python=3.12 -y && conda activate orcalab_lerobot
cd OrcaManipulationv5
bash install.sh
```

验证：`python -c "import orca_gym, lerobot; print('OK')"`

## 1. 起仿真（终端 1，保持运行）

```bash
orcalab    # 选 competition_warehouse 场景 + 布局 competition_warehouse_no_barcode.json → 启动仿真
```

gRPC 默认 `localhost:50051`。

## 2. 采集（终端 2）

```bash
python collect_lerobot.py \
    --pose_file pose_mp_no_barcode.yaml --rand_file rand_no_barcode.yaml \
    --lerobot_out /path/to/out_dataset \
    --repo_id your_org/competition_warehouse_quat \
    --episodes 50 --fps 30
```

完成后输出目录下生成 `meta/ data/ videos/`。

## 3. 回放校验

```bash
python replay_lerobot.py --dataset_dir /path/to/out_dataset --episode 01 --sleep
```

夹爪提前闭合撞物体就调大 `--steps_per_frame`（默认 20）。

## 4. 训练与推理

把数据集传到服务器，按 [训练和推理.md](训练和推理.md) 在服务器端用 JAX 版 openpi 训练并起策略服务，本地再：

```bash
ssh -p <ssh端口> -L 8010:localhost:8010 <user>@<服务器IP>   # 隧道
python eval.py --task_config competition_warehouse.yaml \
    --host localhost --port 8010 --max_steps 500 --episodes 1
```

## 常见问题

- 连不上仿真：确认终端 1 已「启动仿真」、`--orcagym_addr localhost:50051`。
- 相机启动失败：端口 head=7070 / wrist_l=7080 / wrist_r=7090。
- 回放场景与采集不一致：采集加 `--record-scene`，回放加 `--restore-scene`。

## 可选开关

| 选项 | 脚本 | 作用 |
|------|------|------|
| `--record-scene` | collect_lerobot.py | 记录 C12C 随机位姿到 `c12c_poses.json` |
| `--verbose` | collect_lerobot.py | 逐帧诊断日志 |
| `--resume` | collect_lerobot.py | 断点续采 |
| `--restore-scene` | replay_lerobot.py | 复原 C12C 位姿 |
| `--steps_per_frame N` | replay_lerobot.py | 每动作仿真步数（默认 20） |
