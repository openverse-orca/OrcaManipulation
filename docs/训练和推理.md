# 训练和推理

训练在 GPU 服务器端用 **JAX 版 [openpi](https://github.com/Physical-Intelligence/openpi)** 完成，本仓库只负责采集数据和连接策略服务做推理。命令里的 IP / 端口 / 路径按自己的服务器替换。

## 1. 上传数据集到服务器

```bash
rsync -avP /path/to/out_dataset <user>@<服务器IP>:~/datasets/competition_warehouse_quat
```

## 2. 服务器端安装 openpi（JAX）

```bash
git clone https://github.com/Physical-Intelligence/openpi.git && cd openpi
GIT_LFS_SKIP_SMUDGE=1 uv sync          # 安装 JAX 版依赖
```

参考 openpi 官方 README，按自己的 CUDA 版本装好 JAX GPU。

## 3. 改 config.py 注册训练配置

在 openpi 的 `src/openpi/training/config.py` 里加一个 `TrainConfig`，指向上传的数据集（关键是 `repo_id` 与采集时一致、动作维度 16）：

```python
TrainConfig(
    name="competition_warehouse_quat",
    model=pi0.Pi0Config(action_dim=16, action_horizon=50),
    data=LeRobotDataConfig(
        repo_id="your_org/competition_warehouse_quat",   # 与采集 --repo_id 一致
        # base_config 里设置归一化、图像键 cam_head / cam_wrist_l / cam_wrist_r
    ),
    num_train_steps=40000,
),
```

具体字段（归一化、image keys、batch size 等）以 openpi 官方示例为准。

## 4. 训练

```bash
# 先算归一化统计
uv run scripts/compute_norm_stats.py --config-name competition_warehouse_quat
# 训练
uv run scripts/train.py competition_warehouse_quat --exp-name=cw_quat_run1
```

checkpoint 默认存在 `checkpoints/<config>/<exp-name>/<step>/`。

## 5. 起策略服务

```bash
export CUDA_VISIBLE_DEVICES=0
uv run scripts/serve_policy.py \
    --port 8010 \
    --config competition_warehouse_quat \
    --dir checkpoints/competition_warehouse_quat/cw_quat_run1/39999
```
